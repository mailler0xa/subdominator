You might need to install libicu for this to work

### For Debian-based distros (Debian, Kali, Ubuntu, etc)
```bash
sudo apt update
sudo apt install libicu-dev -y
```

### For RHEL, Fedora, CentOS and derivates or relatives
```bash
sudo dnf install libicu-devel
```

### For Alpine Linux
```bash
apk add icu-data-full
```
